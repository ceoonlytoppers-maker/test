# Purushottam SinghaRoy - Portfolio

One page (index.html) and one CSS file. No JavaScript. Font: Poppins (Google Fonts).

- index.html: the whole portfolio
- css/style.css: all the styling
- assets: images and the music file

## Put it on GitHub Pages
1. Make a new repository on GitHub.
2. Upload everything in this folder to the repository root.
3. Settings > Pages > Source: Deploy from a branch > main, folder / (root) > Save.
4. The site opens at https://YOUR-USERNAME.github.io/REPO-NAME/

## Notes
- Say hello: the form opens Gmail with the email to heyceo.onlytoppers@gmail.com already written. The visitor presses send.
- Music: the browser's own player in the top section. Browsers don't allow sound to start by itself, so visitors press play.
- To use your own music, replace assets/audio/bgm.mp3 (keep the name).
